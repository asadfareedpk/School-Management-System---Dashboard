# School Management System (PyQt5 + SQLite)

A desktop application built using Python, PyQt5, SQLite, and Matplotlib.

## Features
- Student Management
- Teacher Management
- Courses & Departments
- Notice Board System
- Dashboard with Charts
- Login System

## Tech Stack
- Python
- PyQt5
- SQLite
- Matplotlib

## Project Type
Desktop Application
